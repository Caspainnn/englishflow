# EnglishFlow｜英语练习流

把听写、词汇和口语串起来的 AI 英语练习助手。

EnglishFlow 是一个可复用的 AI agent skill，包含练习流程、学习记录规范和 Windows 离线听写音频脚本。它不是独立 App，也不自带语音通话或图片识别模型。

## 能做什么

- **听写照片整理**：在支持图片理解的环境中，整理确认后的单词与词义薄弱点，模糊笔迹等待确认。
- **复听音频**：从确认的错词生成 WAV；每词读两遍，两遍间隔 1 秒，词间间隔 3 秒。
- **可选错词本**：开启后记录需要复习的正确单词、来源和实际复习结果，默认不保存错误拼写。
- **词汇激活**：词义回忆 → 常见搭配 → 自己造句 → 情景翻译 → 纠错与整段重译。
- **口语陪练**：日常交流、词汇练习、可选雅思话题；纠错后继续提问。
- **跨对话续练**：记录实际表现与下一步，从保存的检查点继续。

认识单词、跟读成功、独立说出单词是不同的证据。不会把导入照片当成已掌握，也不会凭文字转写评价发音。

## 快速开始

1. 克隆仓库：

   ```bash
   git clone https://github.com/Caspainnn/englishflow.git
   ```

2. 将整个 `skills/english-practice` 文件夹放入支持该 skill 格式的 agent 的技能目录。也可以直接让 agent 读取 [SKILL.md](skills/english-practice/SKILL.md)，按其流程执行。
3. 创建一个自己的学习文件夹，将 [模板](skills/english-practice/assets/templates)中的 `SETTINGS.md` 和 `LEARNING.md` 复制进去，调整目标、语言和复习设置。学习数据放在自己的文件夹。
4. 告诉 agent 学习文件夹的路径：

   > 使用 $english-practice，学习目录是我的 EnglishLearning 文件夹。先读取 SETTINGS.md 和 LEARNING.md，开始今天的英语练习。

首次使用尚无词表，可以先日常对话，也可以上传词表照片。语音练习需要运行环境支持语音；照片整理需要图片理解；保存记录需要文件访问。只有文本时可进行文字练习，发音不评分。

## 我的实际使用工作流

我用下面这套流程把纸上的学习结果逐步变成口头表达。你可以沿用整套流程，也可以只使用需要的环节。

### 1. 背单词、听写

先按自己的教材或词表背单词，再进行听写。这一步由我自行完成，EnglishFlow 接收后续订正照片，不会虚构听写结果。

**为什么做：**先尝试回忆，再对照答案，才能发现哪些词听到了却写不出来、哪些词的含义还不理解。拼写、词义与口语运用是不同的能力，后面分别处理。

### 2. 改错、拍照上传

对照正确词表订正，拍下清晰完整的照片，并说明标记规则。我的习惯是用红色写订正，用左侧三角形标出词义不熟的词。AI 整理最终正确单词与标记，对我的单词列表进行初步把握；模糊笔迹先列出待确认位置，等我确认后再导入。

**为什么做：**保留纸上学习习惯，减少手动录入。明确标记规则可以区分拼写错误与词义薄弱；打勾或没有三角形，也不会自动被认定为已经掌握。

### 3. 构造 Word List 或词库

AI 按照片顺序整理确认后的单词，建立或更新对应 Word List；也可以按自己的材料逐步积累词库。记录来源、词义标记、待确认项与已有练习证据，保留已有词表归属。词表数量与每表大小不限。

针对口语，AI 会初步区分适合日常表达的词、偏书面或专业用途的词，以及尚待判断的词。优先练习适合口语且词义薄弱的词，其他词仍保留在词库中。

**为什么做：**结构化词库支持后续选词、复习和跨对话续练。口语优先级与掌握程度分开记录，避免把暂时不练的词当作已经学会。

### 4. 生成错题听写音频（可选）

确认照片中的订正词后，可以让 AI 生成复听音频。只读正确单词，每词两遍，两遍间隔 1 秒，词间间隔 3 秒，方便再次听写。三角形只表示词义不熟，不会单独成为错词音频的选择依据。

开启错词记录后，可以保存需要复习的正确单词、来源和实际复习状态；默认关闭，不保存错误拼写。具体生成方式与环境要求见下方“听写与复听”。

**为什么做：**集中复习实际出错的词，省去自己录音、剪辑和设置间隔。生成音频只代表材料准备好，真正复听、听写并反馈结果后，才记录复习表现。

### 5. 口语练习

可以把口语练习理解为以下三个阶段。

#### 第一阶段：词义回忆、常见用法与自己造句

AI 从当前词库中优先选出适合口语的薄弱词，通常每五个词组成固定小组。每个词先让我尝试解释含义，再根据回答补充词义、讲一到两个常见搭配，最后让我自己造句。重要错误会得到简短解释与重试，然后继续当前任务。

**为什么做：**回忆检查真实理解，搭配说明词怎么用，自己造句检查能否把词放进表达。听过讲解或重复例句，不等于能自己使用。

#### 第二阶段：情景翻译、针对性纠错与整段重译

完成小组基础练习后，AI 写一段覆盖成员目标含义的连贯中文情景，让我口头翻译。新翻译提示不附英文目标词或参考答案。根据实际回答，AI 提取问题短句进行纠错和重试，再给出同一段完整中文，让我重新翻译整段。

完成后保存并检查小组进度，再开始下一组的第一阶段。未完成内容保持待练，不会因为跳转而被标记完成。中文是默认翻译源语言，可按学习者设置调整。

**为什么做：**把孤立词语放进连续表达。整段重译检查纠错能否回到完整语境，短句跟读正确不代表整段表达稳定。由于此前已经学过目标词，这仍是有提示背景的练习，不会被当作完全独立的掌握证据。

#### 第三阶段：自由话题交流

当天计划的小组练习完成后，进入日常话题对话。AI 根据回答自然追问，不规定必须使用哪些单词。自然出现的已学表达可以记录，没用到某个词不算失败。也可以按需要直接选择日常对话或雅思话题模式。

**为什么做：**从指定词语练习过渡到真实交流，练习根据自己想说的意思选择词语、组织回答。

### 6. 生成记录

AI 在小组边界和结束时保存实际练习证据：词义回忆、提示程度、造句与翻译问题、重试结果、额外表达缺口、未完成任务和下次的具体起点。依次更新会话日志、词表练习日志、词表摘要和学习入口文件。

下次新对话先读取文件，从检查点继续；提前结束也保存部分进度。只有实际发生的练习才进入记录。

**为什么做：**减少每次重新解释进度，让复习依据实际表现安排。照片导入、音频生成、跟读和自主表达分别记录，不会合并成笼统的“已掌握”；没有可访问音频时，也不会凭转写评价发音。

## 听写与复听

上传照片时先说明标记含义，例如“三角形表示词义不熟，红色是订正”。确认模糊单词后，可说：

> 把这张照片里订正的单词生成听写音频。开启错词记录，方便下次复听。

默认 `dictation_history: off`，错词选择只用于本次音频。改为 `on` 后，agent 将确认的正确单词保存到 `Dictation/review.md`。生成音频不会自动标记复习完成。

当前音频 helper 支持 Windows PowerShell、System.Speech 和 Microsoft Zira Desktop，无需在线 TTS API。图片识别与教学由所在 AI 环境完成，可能涉及该环境的费用。其他系统仍可使用练习流程，但需自行提供适配的音频工具；本项目不自动安装替代服务。

从仓库根目录手动生成：

```powershell
& .\skills\english-practice\scripts\New-DictationAudio.ps1 -ListNumber 1 -Words @('engage','athlete') -OutputRoot C:\EnglishLearning
```

在 PowerShell 中也可直接调用脚本并传入 `-Words @('engage','athlete')`。如从其他 shell 调用，推荐使用这种数组方式的 PowerShell 命令，避免参数解析差异。可通过 `-VoiceName` 和 `-TimeZoneId` 指定已安装语音和 Windows 时区。

音频保存在学习目录的 `Artifacts/Dictation/日期/运行时间/Word list 1.wav`，不同运行保留不同版本。默认语速为 Rate -2 加 SSML +25%，并非精确的播放速度倍数。脚本不识别图片；输入必须是确认后的正确单词。

## 学习记录

```text
EnglishLearning/
  SETTINGS.md
  LEARNING.md
  WordLists/WordList-01/
    summary.md
    intake/
    source/
    practice/
  Sessions/
  Dictation/review.md       # 开启错词记录时
  Artifacts/Dictation/
  REVIEW_PLAN.md           # 可选：自己的复习日程
```

词表数量与每表大小不限。照片导入不产生口语评分；未测试保持未测试。中断时保留未完成任务，下一次读取文件继续。只有实际产生记录时才创建会话日志。

## 范围与限制

- 默认用英语练习与反馈，可按要求切换语言；中文情景翻译可换为学习者的母语。
- 雅思是可选模式；自编题会标明练习题，词汇等级不等于雅思分数。
- 音频或文件能力取决于 agent 环境，不保证不同产品之间自动共享状态。
- 学习照片、录音与记录留在自己的学习目录；本仓库不包含作者的个人练习数据。使用 AI 环境时，数据处理遵循该环境的规则。
